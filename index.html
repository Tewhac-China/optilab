    操作说明

    箱庭视角

    • 左键拖动 旋转视角 · 右键拖动 平移 · 滚轮 缩放
    • 单击元件 选中并显示参数
    • 按住拖动元件 沿导轨移动（引导模式下会吸附到理论位置）
    • W A S D 漫游 · Q E 升降 · Shift 加速

    会真实影响结果的调节

    • 针孔微调（左栏调节盘 / 方向键 1 µm）：偏心 δ 使透过率按 exp(−2δ²/w₀²) 骤降，并让照明偏心 → 峰变弱直至被噪声淹没
    • 照明光阑②：真的截断输入面；关到 < 2.9 mm 就会切掉目标轮廓， 同时下游光柱在 3D 里同步变细
    • 检偏器 P2（左栏滑块，或直接看 3D 里的刻度环）：与起偏器 P1 正交 (Δ=90°) 时液晶的振幅调制最深；转偏 → 条纹对比度按 sinΔ 衰减，Δ→0 条纹消失
    • 拖动准直镜离开焦面 → 球面波照明 → 等效谱面离焦、条纹变钝
    • 拖动 CMOS / 输出屏离开后焦面 → 模糊圆卷积，条纹与峰一起劣化
    • 改 f₁ / f₂：探测器会自动跟到新后焦面（练习调焦请手动拖动 CMOS）
    • 光太弱（偏心 / 小光阑）→ 记录信噪比下降，相关峰被噪声淹没

    判据与典型错误

    • 右侧「质量判据」给出条纹对比度 V、针孔透过率、分离度 2a:w、信噪比、 照明均匀度、光阑截断——做错了哪一项立刻变红
    • 「无有效相关峰」表示峰不显著或位置偏离，当前峰位读数不可信
    • 左侧「典型错误」一键施加常见失误，观察结果如何崩，再点一次复原
    • JPS 处理：原始 / 二值化 / 纯相位 / 高通，对比现代方法对峰的改善
    • 输入面 f(x−a) + g(x+a) → 谱面 S = |FT{h}|² → 二次变换 → 峰在 ξ = ±2a·f₂/f₁
